# @capstone/standards

Generated HTTP status code and phrase constants, shared so every worker uses the same values instead of hardcoding them.

```ts
import { ... } from '@capstone/standards/status-codes'
import { ... } from '@capstone/standards/status-phrases'
```

`src/status-codes.ts` and `src/status-phrases.ts` are generated; don't hand-edit them. See [CLAUDE.md](CLAUDE.md) for the generator.
